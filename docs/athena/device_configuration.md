## 3. Device Configuration

Educational ARES supports two device classes: the **Prusa MK4S 3D Printer** and a **Camera**. Devices must be created manually in the settings menu.

### 3.1 Prusa MK4S Printer
* **Creation:** Click the "plus" icon under Prusa Printers in the settings menu.
* **Required Info:** * **Name:** A friendly identifier for use within ARES.
    * **Printer Address:** The IP address formatted as `http://0.0.0.0`.
    * **Username/Password:** Found in the printer's network settings under PrusaLink.
* **UI Controls:** Displays nozzle/bed temperatures and supports movement or homing commands.

### 3.2 Camera
* **Creation:** Add a camera in the settings menu by providing a name.
* **Source:** Select any webcam detected by Windows from the drop-down menu.
* **UI Controls:** Take test pictures and download them as PNG files directly from the dashboard.
